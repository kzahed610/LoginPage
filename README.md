# LoginPage

A sleek, responsive React sign-in / sign-up UI with an animated overlay panel. Built with Vite and plain CSS, this small project demonstrates a modern dark-themed authentication layout that you can copy into your own app.

## Features

- Animated overlay toggling between Sign In and Create Account
- Responsive, centered card layout with dark theme
- Minimal, easy-to-adapt React component structure

## Quick Start

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open http://localhost:5173 (or the address Vite prints) to view the page.

## Build

```bash
npm run build
```

## Notes

- The main UI is implemented in `src/components/AuthPanel.jsx` with styles in `src/components/AuthPanel.css`.
- Feel free to adjust colors and text in the component CSS to match your brand.
